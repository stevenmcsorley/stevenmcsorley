### What I've been building

For the past year I've designed, built and operated a **self-hosted platform of 20+ production web applications** — not just the products, but the entire development lifecycle around them:

**Plan → build → ship → observe → back to plan.**

| Layer | What it does |
|---|---|
| **Project tracker** | Sprints, story points, velocity forecasting, burndown, wiki |
| **CI/CD** | Self-hosted runners, arm64 image builds to GHCR, health-checked deploys, automatic rollback |
| **Error monitoring** | Sentry-style capture and triage across every service |
| **Observability** | OpenTelemetry-native metrics, logs, traces and uptime |
| **Team chat** | Deploy notifications and alert routing |

Monitor alerts file tickets straight back into the tracker, closing the loop. Everything runs containerised behind a Cloudflare tunnel with no open ports. Built and operated solo.

**Products delivered through it** include a multi-tenant HR platform built over 24 tracked sprints to WCAG 2.2 AA, a live UK public-contract intelligence service, a payments ledger, and market-intelligence apps across three verticals sharing one reusable architecture.
